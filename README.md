# KN-NLTE-He_and_Sr
This repository contains the rate equation solver for helium (He) 
and strontium (Sr), and the resulting datasets
used in K. Chiba et al. 2026, [ApJ](https://doi.org/10.3847/1538-4357/aea3fe)
([arXiv:2604.05703](https://arxiv.org/abs/2604.05703)).

For a similar but independent implementation of the solver, 
see also https://github.com/rasmus98/NLTE-Helium
and https://github.com/aayusharyaa/kilonovae

## Contents
- coords-He_vs_Sr/: coordinates of constant-total-optical-depth contours generated by the script in "analysis.ipynb"
- reqlocal/: rate equation solver
- runs/: a sample input file, a driver script and resulting datasets 
- analysis.ipynb: some examples of visualization
- README.md: this file
